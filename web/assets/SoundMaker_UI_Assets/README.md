# SoundMaker UI PNG Assets

This pack combines extracted character-avatar crops from the earlier figure-based UI design with clean PNG geometric motifs created for implementation.

## Assets
- voice_avatar_male.png — character avatar, male sample
- voice_avatar_female.png — character avatar, female sample
- voice_avatar_other.png — character avatar, other sample
- brand_geometry.png — transparent geometry branding mark
- header_sound_geometry.png — transparent wide abstract sound motif
- dots_pattern.png — transparent dotted motif
- corner_geometry.png — transparent corner graphic
- waveform_icon.png — transparent waveform decorative glyph
- design_reference.png — full UI visual reference ONLY; do not use as webpage screenshot background

IMPORTANT: these are concept art exports, not original vector source layers. Avatar upscales cannot restore missing details. Use real HTML/CSS for all text, form fields, borders, tabs, buttons, state indicators, hover, and scroll interactions. UI must implement PRD V1.6 behaviors.
