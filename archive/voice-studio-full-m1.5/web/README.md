# Voice Studio · M1.5 最新交互评审版

HTML5 + CSS3 + Vanilla JavaScript ES Modules。无前端框架、构建步骤或运行时第三方依赖。仅使用本地内存 Mock；不接 MiniMax，不修改 Python Core、真实项目配置或凭据。

## 启动

在项目根目录执行并保持终端运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)；Ctrl+C 停止。不要直接双击 HTML：ES Modules 需要 HTTP，直接打开时页面会显示启动指导。

## 最新操作路径

- 首次打开基础设置，未选角色时只显示“请选择角色”，隐藏参数和应用操作。选中 02 角色后沿用角色名称、声音、参数、试听文本和本次会话固定图标。基础设置保留参数、文本、试听与分配操作；探索更多仍提供模型、音色选择及扩展元数据；音色生成仅占位。
- 01 项目长卡为 **240×56px**，顺序保持头像→试听→名称→设置，设置常显。男/女/其他行共用横滑容器，编号与类别固定。点击主体和试听/设置是独立事件。
- 点击 01 设置：打开对应基础设置，自动收起 03；窄屏滚动并聚焦下方设置长卡。不会清空筛选、角色参数或编辑草稿。
- 声音池单击只选中；双击进入基础设置，窄屏定位设置长卡；键盘 Space 选择、Enter 打开设置。明确可用的音色有独立播放/停止键，只播放本地 Mock 提示音，不自动分配、不解锁生成试听门槛。不可用或可用性 unknown 没有播放键。03 仍可折叠，保留筛选与选择。
- 点击 02 角色后，再点项目卡片主体可直接绑定；来自候选的参数配置仍要取得当前参数模拟试听后，才能加入角色池/项目库。
- 点击默认声音：直接弹出项目声音候选与确认。弹窗内选择不写入；确认后仅更新 Mock 项目默认，取消不改数据。使用项目声音已保存参数，不应用下方面板未保存草稿，也不改变当前角色或编辑器。要把声音池候选设为项目默认，先试听并加入项目库，再在弹窗选择。
- **完成设置**是 02 底部全宽、最大主按钮。角色未分配齐全时显示摘要并阻止通知；齐全时调用内存 Mock Harness 接口并显示确认收据。不会发送真实 Answer、恢复 Agent 或启动生成。

## 配色与布局

`css/tokens.css` 统一颜色、字体、间距、边框、阴影；`css/studio.css` 控制布局与组件状态。声音头像底块按明确元数据统一：

| 类别 | Token | 色值 |
|---|---|---|
| 男声 | `--voice-male` | 蓝绿色 `#4ecdc4` |
| 女声 | `--voice-female` | 红粉色 `#f381a4` |
| 其他 / unknown | `--voice-other` | 黄橙色 `#f2b544` |

项目库与声音池一致；不会按名称或头像推断性别。不可用音色保留类别色，通过虚线边框和明确文字表示不可用。

桌面双栏，01/02 同一大框，03 独立。850px 及以下上下排列，设置区为纵向长卡、内容自然展开，避免原 400px 小卡的内部挤压。页面允许纵向滚动；项目库、角色条、声音池保留各自有界滚动。03 收起后只保留标题与展开按钮。

页头参考新图片使用原创 Bauhaus 几何 SVG；原有生成插画资产保留，声音生成占位仍使用生成装饰图。来源和生成提示词见 [素材说明](assets/README.md)。没有从参考截图裁取头像。

## Mock、状态与调试

- `js/store.js`：集中状态、快照隔离、角色/默认/折叠与编辑动作。
- `js/editor.js`：共享 Tab 草稿、独立对象上下文、能力兼容、参数签名与过期判断。
- `js/api.js`：内存工作区、声音池、试听缓存、revision 保存、`notifyHarness` Mock 回执。
- `js/assignment-flow.js`：试听后应用、命名保存、旧引用/revision 重绑定与重试。
- `js/modules/`：区域组件；`dialog-focus.js` 管理确认/摘要弹窗键盘循环。
- `js/events.js`：最多 100 条事件，含名称、对象 ID、结果与错误。

本机开发入口可打开 Debug；`/?dev=0` 隐藏。可注入声音池空/失败、试听失败、保存失败和 revision 冲突。可观察 `library.settings.open`、`pool.voice.selected`、`pool.collapse.changed`、`settings.basic.open`、`ui.tab.changed`、`requirements.default.quick.*`、`requirements.default.saved`、`flow.complete.click`、`harness.mock.notified` 以及试听/保存事件。

缓存包含规范化声音引用、模型、文本和所有有效声音参数。修改后旧试听标过期；不支持情绪保留原值并说明，不静默覆盖。保存失败保留草稿，重名须明确确认旧引用与 revision。项目保存成功才同步到捕获的任务角色；管理模式允许单独保存。声音、参数、默认与缓存均在内存，刷新重置。CSP 禁止业务网络连接，仅同源静态素材 GET。

## 最新角色状态规则

- 01 卡片前的灰色方框是绑定状态标记，不增加独立勾选操作。尚未绑定当前任务角色时为灰色；绑定后显示对应 02 角色序号。两角色显示两个序号；超过两个显示首个与其余数量，完整角色序号可从提示和可访问描述查看。
- 02 **已分配才亮色，未分配保持暗色**。当前点击/编辑目标只增加描边，不改变明暗。男声蓝绿、女声红粉、其他黄橙；未分配按未知类暗黄橙呈现。
- 已分配声音的分类随绑定冻结，后续别名重绑定不误改旧角色的分类色；不按名称、头像推断性别。
- 红色返回工作台栏已按最新反馈移除；没有新增历史、设置等无业务页面的导航。


## 试听后的命名与应用

“音色名称”输入框由两种操作共用，放在按钮上方；按钮同一行，“加入角色池”在左，“加入项目库”在右。两者都要求有效名称（1–120 字、无首尾空格）。角色池保存的是当前任务的音色名称与配置，不会创建项目别名；项目库仍要求项目内唯一名称，重名走显式重绑定及 revision 检查。


## 基础设置的角色上下文

02 与基础设置共用角色图标；角色载入时从原有本地 SVG 随机分配一次，同一任务内切换角色/Tab、编辑参数、加载候选不会重新随机。刷新开始新的 Mock 会话时可能重新分配。图标不表示性别。

选中角色后首次打开新的项目声音/声音池候选，沿用当前角色草稿的参数、模型、文本与音色名称；后续保留各自修改。相同候选在不同角色下分别存草稿，避免串状态。角色应用或项目保存成功后，角色的名称、声音与参数同步，返回角色时仍保留；Mock 项目声音还沿用角色图标。

没有选角色时，基础设置始终提示“请选择角色”，即使点击项目设置或双击候选也不会绕过；探索更多保留独立音色管理及无任务保存能力。
