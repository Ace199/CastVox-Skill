# 素材来源

此目录 SVG 均为本原型以代码绘制的原创简化图形：`portrait-narrator.svg`、`portrait-reader.svg`、`portrait-soft.svg` 是扁平人物插画；`avatar-placeholder.svg` 是中性占位；`studio.svg` 是几何图标。无外部字体、图库照片或从参考截图裁取的素材。

头像是装饰，不表示真实人物，也不作为音色性别分类依据。配色与项目视觉方向一致。

`mock-preview.wav` 是本地生成的 2 秒提示音，用于验证播放、缓存与分配流程；不是 MiniMax 音频，不模拟声音或参数效果。页面加载素材仅使用同源静态 GET。
