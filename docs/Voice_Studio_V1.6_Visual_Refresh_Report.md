# Voice Studio V1.6 视觉重构

## 最新审核调整

用户再次确认：头像底框向右下错位，人物偏左突出；02 编号红底；三个默认卡恢复同一行（覆盖下文两行的历史设计）。修改 refresh.css、README 和对应浏览器断言。浏览器 36/36 PASS，实际服务五视口 PASS，已复核桌面与 320px 窄屏截图。业务逻辑未修改。

日期：2026-10-16。基于 PRD V1.6、用户最新要求与 `web/assets/SoundMaker_UI_Assets/README.md`、`design_reference.png`。本次只调整前端展示与头像映射，未改 Python Core、Schema、凭据、Provider 或付费逻辑。原有业务继续使用内存 Mock，不宣称真实持久化或 Harness 恢复。

## 实现

- 桌面双栏约 59% / 41%；暖白底、墨蓝细描边、钴蓝选中、明黄主按钮、少量硬阴影。小屏上下堆叠，紧凑顶栏只放几何和声波。
- 三行项目声音保持固定分类标签和共享横滚，横向短卡保留所有操作；当前需求独立横滚。
- 默认设置第一行通用默认，第二行男声/女声。颜色、可空、显式确认保存与草稿逻辑不变。
- 头像使用现有 `man / women / unknow` SVG。按稳定声音 ID 与用户明确的分类映射，不按名字或厂商 ID 推断。33px 底色框在左下，41×45px 人物向上、向右突出。未分配浅色、分配亮色，角色继承所分配声音头像；未分配角色继续灰底问号，双击说明浮层保留。
- 添加、设置、More Tools 保留。厂商与模型、名称与分类分别并排，Voice ID 单行；固定来源只读。默认保存、设置保存、添加和完成设置保持不同动作。
- PNG 包本就在静态资源目录，直接引用几何资源，未重复复制，未使用截图作为背景或切片按钮。所有文案和状态是 DOM。

## 与参考图的差异

按最新要求，参考图几何头像替换为用户 SVG 人物，头像不居中铺满底框；未分配任务仍问号。并排三默认改为两行。背景与填充不使用参考图的渐变。保留项目卡片的分配序号标记与现有配置文件按钮。顶栏更紧凑、不模拟桌面窗口控制按钮；装饰没有业务含义，不产生新交互。尚未使用的其余头像可以后续扩充映射，未新增头像选择功能。
