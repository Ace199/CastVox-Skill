关键修复前证据（仅保留必要错误）：

- 模型脱敏复现：`test_credential_copied_into_model_metadata_is_rejected` 原失败，`AssertionError: 'PRIVATE_RANDOM_VALUE' unexpectedly found`；修复后通过。
- 初轮试听回归：29 项中 1 失败、7 错误；根因是 Windows 对只读句柄 `fsync` 返回 `OSError: [Errno 9] Bad file descriptor`。改为可写句柄同步后通过。
- 参数签名规范化：有效 speed 固定编码为 float、pitch 为 int，避免相同有效数值 `1` / `1.0` 被错误判为旧参数。
- 未分类 Provider 异常统一作为结果未知处理，不能仅凭异常类型自动重复可能收费的请求。

## 剩余问题及真实联调门槛

1. **本轮离线验收完成，不代表 V1.6 产品全量完成。** MiniMax 和火山真实合成均未实现，未进行真实鉴权、余额、模型权限、跨区或效果测试。火山生产配置路径/契约仍未确定。
2. 真正的语速/声调描述器、API 映射、情绪省略、显式停顿编码及真实句级时标，需要获得授权后单独联调。Fake 静音只验证结构、文件和时序。
3. UI 接入由 Agent 2 完成。新的安全服务不会自动把现有 Mock 页面改成真实持久化页面；会话凭据注入、播放器状态、保存确认与草稿仍需 UI 验收。接口见 `V1.6_Core_API.md`。
4. 只支持 WAV；默认 paragraph/句级字幕已验。MP3 默认需本地编码/探测工具接入后再启用。whole/sentence 还应补充专门模式回归。
5. 结构化稿件是当前输入契约。自动长文断句、舞台备注剔除审计、语义角色/情绪规划尚未实现。
6. 未知计费状态有安全阻断，但没有人工对账/解除流程。成功产物损坏后的重新生成目前仅在 Fake 路径验证，真实付费 Adapter 接入前应增加修复授权策略。
7. 本轮覆盖 OS 锁下并发 CAS 与结果顺序，不声称验证了多进程并行合成、断电/磁盘耗尽/同步盘持久性或长时负载。试听当前在任务结算后提取；不按网络完成先后抢占。
8. 回滚只允许迁移后尚未修改（revision=0）且旧文件未变的情况；有新业务数据时拒绝回滚，防止丢失。本轮没有改写任何真实用户项目或凭据。
9. 工作目录没有 Git 元数据，无法提供 Git diff/commit 证据；交付以文件清单和自动化结果为准。未重置工作区，也未修改其他 Agent 的 UI 文件。
