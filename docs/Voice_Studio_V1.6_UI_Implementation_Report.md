在用户使用的内置浏览器复现：旧缓存 providers.js 不包含新导出 openProviderConfig，导致模块链接失败，停留在启动提示。干净 Chrome 上正常，因此此前隔离浏览器测试未覆盖这一缓存状态。

studio_server.py 为响应添加 no-store，并对静态资源忽略旧 If-Modified-Since；index.html、app.js、view.js 为此次变更的模块链添加版本参数，使已缓存的旧客户端也能恢复。实际内置浏览器刷新后已显示完整项目、角色、Tab 和配置按钮。新增静态模块缓存验证测试，Studio 专项 8/8 PASS。业务逻辑与真实凭据未修改。

## Mock 对接约定

当前结构标记 `1.6-ui-mock`，不是持久化 Schema 迁移。声音使用稳定内部 ID，记录 `name/category/source/settings/deleted/preview`；固定来源包含 `provider/region/model/voice_id`。默认保存 ID 引用，软删除或分类不匹配时显示未设置但保留原引用；撤销不覆盖后来保存的新默认。

角色显式分配复制来源与参数快照。项目编辑不重算既有任务快照；真实历史 Job Snapshot 存储仍由 Core 负责。模型来自脱敏查询；能力支持模型级或厂商按模型索引的 `capabilities`，控制项包含 `supported/verified/min/max/step/neutral/reason`。仅隔离 Mock fixture 注入 `mock_only` 示例能力。

试听仅接受同源许可路径，绑定来源与有效参数签名；新样本成功后再替换旧状态。Mock revision、提交去重和失败注入用于前端验证，不表示真实事务、文件原子保存或 Harness 接入完成。
