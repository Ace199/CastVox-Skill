## 能力核对

用户提供的豆包能力说明提到：可生成旁白、对话、音效、音乐、环境声及复合音频；可使用 1～3 条参考音频；单次 1～120 秒，以 WAV 交付。这些是用户提供的能力线索，不是本仓库实测结果。调用前以当前实际工具 schema/说明核实，不把参考数量、时长或 WAV 写成不可变保证。音频转写/总结是另一个需求，不为生成配音自动调用。

没有实际可调用工具时说明不可用，提供项目音色选项供用户决定，不自动切换、不猜造命令、不读源码、不额外安装插件。仅读取本说明，不连带读取 Kimi 或豆包网页恢复文档。

## 生成与交付

1. 使用原文/已审阅文案，根据角色给出适合的声线、语气与节奏。参考音频只在用户已提供或明确选择时使用，按当前工具的授权与能力要求处理，不自动索要或上传参考。
2. 直接使用当前内置音频工具的真实入口与参数。不创建 SoundMaker Question/Answer、项目绑定或收费 Job，不要求厂商 API Key；已有明确且范围完整的生成请求直接执行，额外费用或授权按实际工具要求处理。
3. 内置音频不等于可复用音色，未返回并核实可复用 `voice_id` 时，**不加入项目声音库**，不把文件 URL、生成任务 ID 作为声音 ID。即使返回某种声音标识，也不自动入库：需要另行明确其可复用契约及已有适配支持。
4. 交付实际音频播放/下载入口，能保存到项目时保留文件。格式、时长、多角色效果和字幕只按实际结果报告；不保证跨次生成音色一致。用户要求精确绑定、逐句版本或稳定复用时，解释范围差异并提供项目音色路径，不静默切换。
5. 内置结果的修改沿用本工具及原文/描述，只核对变更范围，不读取项目修订文档、不创建绑定版本；不能保证对整段音频仅局部换声。失败保留结果并按工具实际状态说明，状态未知先核对，不盲目重生成或自动换厂商。没有独立分句、字幕或本地文件时直接说明，不为补齐项目交付模板额外生成、安装工具或编造路径。
