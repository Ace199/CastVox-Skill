# Kimi 内置音频（仅选项 3 时读取）

Kimi 当前工具名为 `audio_generation`（用户确认）。只在当前宿主为 Kimi、用户选择内置生成且当前会话确有该工具时使用；直接调用该工具，不将其拼成 Shell 命令或 Python 接口。参数、时长、参考音频和输出格式以当前工具说明为准；工具缺失时说明不可用，不猜造调用。不读取其他应用或网页恢复文档，不查源码。

1. 使用用户原文或已审阅文案，为角色选择适合的年龄感、声线、语气和节奏；只向实际工具传入支持的要求。未提供的角色特征仅作为生成建议，不说成事实。已有明确生成指令、内容与范围无需重复询问；需要改文案、付费或额外授权时按实际工具要求处理。
2. 直接调用当前内置音频工具。不创建 SoundMaker Question/Answer、绑定或收费 Job，不读取 MiniMax 配置，也不调用本 skill 自身作为音频工具。
3. 生成结果是音频文件，**不加入项目声音库**或任何音色数据库；不虚构 `voice_id`，不将音频路径、URL 或工具任务 ID 当成可复用音色。不承诺跨次调用保持同一声音。
4. 提供工具实际返回的音频播放/下载入口，保留用户可访问的结果；能合法下载到项目时可保存音频及简短来源说明，这不是声音入库。只报告实际格式、时长和字幕状态，没有字幕就不编造。
5. 想改声或重生成时沿用本工具与已知原文/描述，仅核对变更范围，不读项目修订文档或重新询问生成路径；不能保证只替换整段中的一个角色。需要稳定音色绑定或长期工作流时让用户选择是否切换，不能自动把结果转换成库内声音。
6. 失败按实际工具返回报告，保留已有音频；状态不明时先核对已有结果，不盲目重复生成，不自动切换厂商/工具。内置交付只保留实际音频及可用信息，不为补分句、字幕或项目目录额外生成或安装媒体工具。
