# MakeSoundSkill / Voice Studio — Visual Direction V1

> 日期：2026-10-15  
> 状态：**视觉探索规范，不是已经批准的最终视觉稿**  
> 目标：为已确认的单屏 Voice Assignment Workspace 建立一致的配色、描边、卡片、阴影、微交互与排版方向。

## 0. 核心视觉定位

**Cel Shading × Bauhaus / Mondrian Color × Neo-Brutalist Feedback，局部 Memphis 点缀。**

- **主视觉基础：Cel Shading**——赛璐璐动画式纯色块、清晰黑色墨线、硬偏移阴影、没有渐变。
- **信息秩序：Bauhaus / Mondrian**——几何构图、网格、强调色与留白有功能意义，而不是随机上色。
- **交互反馈：Neo-Brutalist Playful**——按钮实体按压、硬阴影收缩、有限位移；避免整页过度弹跳。
- **插画/节奏：Memphis**——在标题、小图形和少量空白处放置构成元素，不进入密集设置区。

推荐比重仅是设计方向：**Cel Shading 约 70%，Bauhaus/Mondrian 约 20%，Memphis/Playful 约 10%**；不作为机械量化验收。

### 不采用

玻璃拟态、毛玻璃、霓虹渐变、无处不在的圆角、浮夸 3D 投影、复杂纹理背景、大面积贴纸干扰控件；不要把工具页设计成插画海报。

## 1. 参考来源及其作用

| 来源 | 借鉴重点 | 不照搬的内容 |
|---|---|---|
| [StyleKit — Cel Shading](https://www.stylekit.top/styles/cel-shading/showcase) | **主依据**：深色描边、平涂、硬阴影、按钮 press feedback、卡片、标签 | 漫画感大标题不必挤进全部工具区 |
| [StyleKit — Bauhaus](https://www.stylekit.top/styles/bauhaus/showcase) | 红黄蓝与黑白、几何秩序、硬结构与功能优先 | 不要求全站严格只能五色 |
| [StyleKit — Neo-Brutalist Playful](https://www.stylekit.top/styles/neo-brutalist-playful/showcase) | 硬边、按压反馈、少量彩色阴影与短弹性感 | 不要所有卡片都旋转或弹跳 |
| 用户上传的彩色插画参考 | 色块切割、轮廓线、平面构成、艺术海报气质 | 不自动提取插画角色并作为正式 UI 资产 |
| 用户手绘 Voice Studio 布局 | 区域分布、男/女两行、需求按钮、右侧面板位置 | 草图的线宽与尺寸不视为实际 CSS 像素值 |

官方/StyleKit 页面是风格参考，非 MakeSoundSkill 产品功能证据；实际控件必须遵循 Voice Studio PRD。

## 2. 色彩 Tokens（提案，可在高保真阶段微调）

| Token | Hex | 用途 |
|---|---|---|
| `ink` | `#1A1A2E` | 标题、正文、描边、硬阴影 |
| `paper` | `#FAFAF5` | 主背景与卡片大面积底色 |
| `white` | `#FFFFFF` | 输入区与第二层面板 |
| `blue` | `#4EA8DE` | 角色选中、信息状态、部分分组标识 |
| `red` | `#E63946` | 强调与错误状态（错误不只靠颜色） |
| `yellow` | `#F1C40F` | 主要动作、焦点提示与重要按钮 |
| `green` | `#2ECC71` | 明确成功、已完成绑定 |
| `pink` | `#F381A4` | 某些角色识别标签，不作为性别语义硬编码 |
| `cyan` | `#4ECDC4` | 小范围辅助标签/状态 |
| `muted` | `#667085` | 次级说明和辅助文字 |

**色彩规则**：整体 70–80% 空间留给近白/白；纯色用于状态和重点交互；不同角色的 ID 颜色应稳定、可追踪，但**不把性别与某一种颜色做强绑定**。非颜色标识（序号、名称、图标、形状）同时存在。

## 3. 边框、阴影、圆角与网格

建议首版 CSS token：

```css
:root {
  --ink: #1a1a2e;
  --paper: #fafaf5;
  --blue: #4ea8de;
  --yellow: #f1c40f;
  --border-structural: 3px solid var(--ink);
  --border-control: 2px solid var(--ink);
  --shadow-card: 4px 4px 0 var(--ink);
  --shadow-button: 3px 3px 0 var(--ink);
  --radius: 0px;
}
```

- 大区块：2–3px 清晰描边，靠网格间距与留白区隔。
- 声音卡：2px 黑边，默认小硬阴影或无阴影；选中态可叠加外圈强调描边。
- 右侧内容面板：保持高信息可读性，不要给每个字段一层巨大阴影。
- 圆角默认 0；头像、声波图标等特殊素材可例外，不改变“硬卡片”的整体轮廓。
- 推荐布局：桌面端左侧信息区 55–62%，右侧详情 38–45%，实际按最小可读宽度调节；窄屏可改成上下堆叠或抽屉，不出现横向页面溢出。

## 4. 字体与排版

- 标题层：高字重几何无衬线，可少量借鉴 Bauhaus 海报式大文字；长说明不使用装饰字。
- 操作正文：优先系统可用的中文无衬线，保证中文、英文 Voice ID、路径和数值输入清晰。
- 字号层级：工作台标题 24–32px；区域标题 16–20px；正文 13–15px；控件说明 11–12px。不要让海报式 H1 占满工具屏幕。
- 声音名称过长：ellipsis，但 hover/focus 下可以显示完整 tooltip。文字变化不能挤走试听按钮。

## 5. 组件外观及交互规范

### 5.1 项目声音卡（最关键）

- 头像 / 声音 icon / 音色名称 / **右侧隐藏设置图标**。
- Hover/focus 后设置图标从右滑入或显现，**声卡外框尺寸与位置完全不变**、试听按钮固定、名称文本向左收缩。
- 设置图标点击打开右侧**基础设置**；点击卡片主体对当前任务角色执行绑定。两个点击区域不能冲突。
- 已绑定角色后：角色按钮出现明确标记，而不把项目库卡片永久改成“这个角色专属”。
- 预留 touch 设备的设置菜单；键盘焦点表现不弱于 hover。

### 5.2 需求角色按钮

- 同一横滑条内展示 Agent 识别的角色，序号与名称同显。
- 当前选中：**双描边或外圈强调色**，与“已完成分配”的绿色勾选彼此独立。
- 默认声音：固定在竖向分隔线左侧；保持与普通角色不同的标记（例如星/书签），表示**项目持久默认**。
- 增减角色时项目音色区的滚动不受影响。

### 5.3 声音池卡片

- 下方声音池可比项目库卡片更简洁：音色名、可核实标签、试听入口、选中态。
- 官方试听缓存不存在时按钮标为「生成试听」（可能产生费用），而不是伪装立即免费播放。
- 选中卡片后右侧探索更多进入目标详情。来源不明性别显示未分类，而不是伪装为硬性女声筛选结果。

### 5.4 设置面板与表单

- Tab 使用 2px 硬边 + 纯色选中背景；初始激活 **探索更多**。
- 基础设置只调整现有声音的情绪、语速、音量、LaTeX、文本规范化、试听文本；**不显示音色选择与 Pitch**。
- 探索更多附加模型和音色选择；其余组件、试听状态和保存动作复用。
- 情绪按钮用小型方角块，禁用态保持可读并显示原因。
- 滑块本体可比其他卡片更克制，保持数字精度；可键盘调整。
- 试听区包含可编辑多行文本、费用提示、生成按钮、音频播放控件、状态说明。
- 按钮：`加入角色池` 与 `加入项目库` 语义不同。项目库可保存后同步加入当前角色，前提是存在对应的任务角色；默认声音独立确认保存。

### 5.5 按钮动画（短、明确）

```css
.neo-button {
  border: 2px solid var(--ink);
  box-shadow: 3px 3px 0 var(--ink);
  transition: transform 130ms ease-out, box-shadow 130ms ease-out;
}
.neo-button:hover { box-shadow: 5px 5px 0 var(--ink); }
.neo-button:active { transform: translate(3px, 3px); box-shadow: 0 0 0 var(--ink); }
.neo-button:focus-visible { outline: 3px solid var(--blue); outline-offset: 3px; }
@media (prefers-reduced-motion: reduce) {
  .neo-button { transition: none; }
}
```

少量徽标可以 ±1–2° 倾斜，但**所有设置表单与长文本禁止歪斜**。避免持续摇晃、弹跳或视差。

## 6. 页面色彩节奏（单屏）

| 区域 | 建议视觉强度 | 处理 |
|---|---|---|
| 顶部项目音色库 | 中 | 浅色背景，分组有少量色条；卡片主要白底黑线 |
| 当前需求按钮区 | 高 | 用纯色和特殊描边突出“正在分配哪个角色” |
| 下方声音池 | 低到中 | 规则卡片阵列，筛选信息明显，降低装饰 |
| 右侧探索更多 | 中 | 清晰控件层次，试听/保存按钮为视觉焦点 |
| 音色生成（占位） | 低 | 不制作尚未确认的生成 UI，不诱导用户点击无效业务操作 |
| 完成设置 | 高但单一 | 仅当前请求需要时出现明确的完成/提交 CTA |

## 7. 建议先设计的 5 个组件

1. **声音卡**：默认 / hover 设定按钮展开 / active 分配 / focus / disabled。
2. **需求角色 Chip**：未绑定 / 选中 / 已绑定 / 选中且已绑定；「默认声音」的持久语义。
3. **Tab**：探索更多默认，基础设置由项目卡设置按钮打开，状态共享。
4. **试听模块**：当前参数未试听 / 生成中 / 命中缓存 / 成功 / 旧参数 / 失败。
5. **操作按钮**：加入角色池 / 加入项目库 / 保存项目默认 / 完成设置，明确主次。

先做这五组状态的统一组件页，再将它们放回完整工作台的一屏，比直接把全部页面上色更可控。

## 8. 高保真探索验收标准

- 视觉：无渐变/玻璃、无圆角泛滥；黑描边、平涂、硬阴影与纯色结构稳定。
- 布局：项目男/女两行**共用水平滚动**；角色按钮**独立横滑**；默认声音固定；右侧详情可用。
- 交互：hover 设置按钮出现但卡片尺寸不动；试听 icon 位置不变；正常点击卡片与点击设置图标不冲突。
- 语义：颜色不独立承载角色状态，声音选中与角色选中明显区分；取消/保存/试听各有真实状态表现。
- 工程：CSS token 可调整；键盘可操作、支持 reduced motion；窄屏无页面横溢出。
- 范围：先做 Mock 自包含 HTML 的**一屏高保真视觉探索**；不接真实 MiniMax、不新建音色、不重写 M1 数据协议。

## 9. 给 Codex / Effective HTML 的可执行视觉 Brief

> 基于 `MakeSoundSkill_Voice_Studio_PRD_V1.3_2026-10-15.md` 和本 Visual Direction，为 Voice Studio 单屏工作台制作高保真自包含 HTML。页面按用户手绘图：左侧上方为两行共用横滑的项目音色库，下一条为独立横滑的角色需求区且项目默认声音固定在左，下面是声音池；右侧是基础设置、探索更多、音色生成占位的选项卡。设计采用 Cel Shading 赛璐璐 UI：深色粗描边、平涂纯色、硬偏移阴影、无渐变、基本无圆角；用 Bauhaus/Mondrian 的红黄蓝黑白建立色彩节奏，少量 Memphis 色彩点缀与 Neo-Brutalist 的按压反馈。务必避免为了视觉改动逻辑。首先做声音卡、角色 Chip、Tab、试听模块、动作按钮的状态稿，再整合一屏。Mock 数据；不调用任何 MiniMax API，不改 M1 数据模型。需展示可点击/可操作状态，并报告窄屏、键盘与 hover/focus 检查结果。
